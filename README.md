# Shirley Hsuan Kuei - Personal Portfolio

這是我個人專屬的履歷與作品集網站，採用 HTML5 與 CSS3 開發，具備響應式網頁設計（RWD）以適應各種行動裝置與桌面螢幕。

## 頁面功能 (Features)
- **個人自我介紹**：跨國專案、知識管理與醫材法規背景概述。
- **專業技能標籤**：直觀展示核心技術與管理工具。
- **專案經歷區塊**：時間軸排序的核心工作經歷與專案成效。
- **聯絡管道**：點擊即可開啟郵件應用的 Email 連結。

## 技術棧 (Tech Stack)
- HTML5 (語意化標籤)
- CSS3 (Flexbox, Media Queries 響應式設計)
